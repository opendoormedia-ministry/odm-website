<p>This guide walks you through setting up a free GitHub account, creating a repository for your project, and giving Open Door Media admin access to work on it.</p>
<hr>
<h2>Part 1: Create Your GitHub Account</h2>
<ol><li>Go to <a href="https://github.com" target="_blank" rel="noopener noreferrer">github.com</a></li><li>Click <strong>Sign up</strong> in the top-right corner.</li><li>Enter the following:<ul><li>Email address: [<strong>YOUR EMAIL ADDRESS]</strong></li><li>Password: <strong>[CREATE A SECURE PASSWORD]</strong></li><li>Username: <strong>[CHOOSE A USERNAME]</strong><ul><li>This will be public and part of your account URL (e.g., <code>github.com/yourusername</code>). Business-related usernames (like your company name) are recommended if this account will manage business projects.</li></ul></li></ul></li><li>Complete the verification puzzle if prompted.</li><li>Check your email inbox (<strong>[YOUR EMAIL ADDRESS]</strong>) for a verification code from GitHub, and enter it on the signup page.</li><li>When asked "How many people will be using this account?", select <strong>Just me</strong>.</li><li>When asked about your GitHub plan, select <strong>Free</strong> — this covers everything needed for this project.</li><li>You can skip any additional setup prompts (personalization surveys, etc.) — just look for a <strong>Skip</strong> link.</li></ol>
<p>You now have a GitHub account. Keep your username, email, and password somewhere safe (a password manager is ideal).</p>
<hr>
<h2>Part 2: Create a Repository</h2>
<p>A repository ("repo") is where your website's code and files will live.</p>
<ol><li>Once logged in, click the <strong>+</strong> icon in the top-right corner, then select <strong>New repository</strong>.</li><li>Fill in the repository details:<ul><li><strong>Repository name:</strong> <strong>[e.g., yourbusinessname-website]</strong></li><li><strong>Description (optional):</strong> <strong>[SHORT DESCRIPTION OF THE PROJECT]</strong></li><li><strong>Visibility:</strong> Choose <strong>Private</strong> (recommended, so the code isn't publicly visible) unless you have a specific reason to make it public.</li></ul></li><li>Leave the <u>"Initialize this repository with"</u> options unchecked unless we have told you otherwise.</li><li>Click <strong>Create repository</strong>.</li></ol>
<p>Your repository is now created. Its address will look like: <code>github.com/[YOUR USERNAME]/[YOUR REPOSITORY NAME]</code></p>
<hr>
<h2>Part 3: Add Your Developer as a Collaborator with Admin Access</h2>
<p>This step gives us the ability to manage the repository on your behalf, while you remain the account owner.</p>
<ol><li>From your repository page, click <strong>Settings</strong> (top menu bar of the repo, not your account settings).</li><li>In the left sidebar, click <strong>Collaborators</strong> (you may be asked to re-enter your password to confirm).</li><li>Click <strong>Add people</strong>.</li><li>Enter Open Door Media's GitHub username:&nbsp;<strong>open-door-media</strong></li><li>Once they appear in the search results, click their name to select them.</li><li>Choose their permission level: select <strong>Admin</strong>.</li><li>Click <strong>Add open-door-media to this repository</strong>.</li><li>We will receive an email invitation and must accept it before access is active. Let us know to check our inbox.</li></ol>
