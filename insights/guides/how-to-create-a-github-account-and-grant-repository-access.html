How to Create a GitHub Account and Grant Repository Access

Open Door Media · July 24, 2026

This guide walks you through setting up a free GitHub account, creating a repository for your project, and giving your developer admin access to work on it.

---

Part 1: Create Your GitHub Account

  1. Go to [github.com](https://github.com)
  2. Click Sign up in the top-right corner.
  3. Enter the following:
  4. Complete the verification puzzle if prompted.
  5. Check your email inbox ([YOUR EMAIL ADDRESS]) for a verification code from GitHub, and enter it on the signup page.
  6. When asked "How many people will be using this account?", select Just me.
  7. When asked about your GitHub plan, select Free — this covers everything needed for this project.
  8. You can skip any additional setup prompts (personalization surveys, etc.) — just look for a Skip link.

You now have a GitHub account. Keep your username, email, and password somewhere safe (a password manager is ideal).

---

Part 2: Create a Repository

A repository ("repo") is where your website's code and files will live.

  1. Once logged in, click the + icon in the top-right corner, then select New repository.
  2. Fill in the repository details:
  3. Leave the "Initialize this repository with" options unchecked unless your developer has told you otherwise.
  4. Click Create repository.

Your repository is now created. Its address will look like: github.com/[YOUR USERNAME]/[YOUR REPOSITORY NAME]

---

Part 3: Add Your Developer as a Collaborator with Admin Access

This step gives your developer the ability to manage the repository on your behalf, while you remain the account owner.

  1. From your repository page, click Settings (top menu bar of the repo, not your account settings).
  2. In the left sidebar, click Collaborators (you may be asked to re-enter your password to confirm).
  3. Click Add people.
  4. Enter your developer's GitHub username, or email:
  5. Once they appear in the search results, click their name to select them.
  6. Choose their permission level: select Admin.
  7. Click Add [developer's username] to this repository.
  8. Your developer will receive an email invitation and must accept it before access is active. Let them know to check their inbox.
